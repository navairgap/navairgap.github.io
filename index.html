I'm a defensive security enthusiast and backend developer. I build tools that watch networks quietly — passive auditors, rogue-device detectors, and honest reports that tell people exactly what to fix and how.

My philosophy: security tools should be passive, local-first, and honest about what they can't do. SentinelWiFi enforces that in CI — a grep that fails the build if any offensive capability ever enters the codebase.

When I'm not auditing networks: real-time systems, Web3 experiments, CTFs.
